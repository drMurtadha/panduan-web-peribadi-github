# Panduan Membina Web Peribadi Akademik di GitHub

Bahan webinar anjuran Biro Pembangunan dan Budaya Ilmu, Institusi Pembangunan Felo (IPF), UTM. Disediakan oleh Assoc. Prof. Dr. Mohd Murtadha bin Mohamad, Fakulti Komputeran, UTM.

**[Baca panduan lengkap](panduan-web-peribadi-github.md)**

Panduan ini menerangkan cara membina laman profil akademik percuma dengan GitHub Pages, menyusun CV sebagai data JSON, menarik senarai karya daripada ORCID dan Scopus, serta menjadualkan kemas kini melalui GitHub Actions. Ia ditulis untuk penyelidik yang bukan pengaturcara.

Untuk mencuba contoh, sediakan akaun GitHub, ORCID iD, Scopus Author ID dan Scopus API key mengikut langkah dalam panduan. Semak data peribadi sebelum menerbitkan repositori awam.

> Contoh JavaScript dalam panduan memaparkan data ORCID. Jika mahu memaparkan data Scopus bersama ORCID, tambah langkah penggabungan dan padankan karya menggunakan DOI.
